## What FL Tools Core Does

- Keeps installed FL Tools products working together.
- Provides the shared launcher, menus, themes, dialogs, shortcut card, and terminology reference.
- Keeps appearance, notifications, updates, and troubleshooting consistent across products.
- Uses rounded rectangular controls, toggle switches, and accessible helper tips.
